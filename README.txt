# C.H.I.C.K.EN.S — Quinta do Enrico

Pacote para publicar gratuitamente no GitHub Pages.

1. Crie um repositório público no GitHub, por exemplo `quinta-do-enrico`.
2. Carregue os ficheiros `index.html` e `icone.png` na raiz do repositório (não carregue apenas o ZIP).
3. Vá a Settings → Pages → Build and deployment → Deploy from a branch.
4. Escolha a branch `main` e a pasta `/(root)`, depois Save.
5. Aguarde a publicação e abra o endereço indicado em Settings → Pages.

Endereços habituais (substitua USUARIO pelo nome da conta GitHub):
- Jogo: https://USUARIO.github.io/quinta-do-enrico/
- Ícone: https://USUARIO.github.io/quinta-do-enrico/icone.png

Nota: a publicação é pública. O jogo inclui música comercial e o jingle da Agriloja; publique apenas se tiver os direitos/autorização necessários para disponibilizar esses áudios publicamente.
